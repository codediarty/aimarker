  2. </body> 바로 위에 붙여 넣고 저장합니다. 모바일 디자인에도 한 번 더 넣습니다.

  2. 테마를 직접 고친다면 footer.php 의 </body> 바로 위에 넣습니다.
  1. 디자인 → 디자인 편집에서 하단 공통 영역(footer)을 엽니다.
  2. 맨 아래에 붙여 넣고 저장합니다. 모바일 스킨에도 한 번 더 넣습니다.
  1. 온라인 스토어 → 테마 → 코드 편집에서 theme.liquid 를 엽니다.
  2. </body> 바로 위에 붙여 넣고 저장합니다.
  1. 설정 → 사용자 지정 코드 → 코드 추가를 누릅니다.
