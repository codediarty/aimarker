이 화면은 운영자만 씁니다. 아래 단추를 누르면 등록된 운영자 메일로 관리 링크(2일)가 갑니다. 메일의 단추를 눌러 들어오세요.

관리 링크는 비밀번호처럼 다뤄 주세요. 다른 사람에게 보내지 마세요.

주문

결제가 확인되면 이용권 보내기를 누르세요. 코드가 주문한 이메일로 바로 가고, 주문 상태가 '이용권 보냄'으로 바뀝니다.

이용권 직접 만들기

계좌 이체 · 쿠폰 · 제휴처럼 주문 없이 줄 때 씁니다. 받는 메일을 적으면 코드가 그 메일로 가고, 비워 두면 코드를 이 화면에만 한 번 보여 드립니다(최대 20개).

이용권

원래 코드는 저장하지 않습니다(해시만). 코드를 잃어버린 분께는 새로 만들어 보내고, 예전 이용권은 중지하세요.

결제

바로 결제(토스페이먼츠)는 Apps Script 프로젝트 설정의 스크립트 속성 TOSS_CLIENT_KEY · TOSS_SECRET_KEY로 켭니다. 꺼져 있을 때 주문한 분이 보는 결제 안내 글과 상품별 결제 링크는 AM_PAY_GUIDE · AM_BUY_LINKS로 바꿉니다.

보안

관리 링크가 새어 나갔다면 모든 관리 링크를 끊으세요. 그동안 보낸 링크가 모두 무효가 되고, 새 링크가 운영자 메일로 갑니다.
