  3. 상품 구조화 데이터 넣기

    상품 쪽에 Product 정보(이름 · 이미지 · 가격 · 브랜드 · 재고)를 JSON-LD 로 넣고, 사이트 맨 위에 llms.txt 를 올립니다.

    진단이 붙여 넣을 코드를 만들어 드림

  4. AI 상품 피드 만들어 두기

    상품 주소를 넣고 CSV · JSON 피드를 받아 둡니다. 쇼핑 광고 · 판매자 센터 등록과 API 연동에 씁니다.

    고객이 AI에게 물을 만한 질문과 답을 상세페이지에 FAQ 로 올립니다. 사이즈 · 소재 · 배송 · 교환처럼 구체적일수록 좋습니다.

    진단이 질문 틀을 드림

  6. AI 이미지 표시 · 문구 점검

자주 묻는 것

AI 커머스 엔진, 이것이 궁금합니다

스마트스토어 · 오픈마켓 상품도 되나요?

외부에서 쪽을 읽지 못하게 막아 둔 곳은 피드를 만들지 못할 수 있습니다. 이때는 자체몰(카페24 · 아임웹 · 고도몰 등) 상품 쪽을 넣거나, 상품 이미지 자동 마킹(대체 텍스트 · AI 표시)부터 쓰세요.

만든 피드는 어디에 쓰나요?

CSV 는 쇼핑 광고 · 판매자 센터처럼 상품 목록을 받는 곳에 올릴 때, JSON 은 사이트 구조화 데이터 · API 연동에 씁니다. 항목 이름(id · title · description · link · image_link · price · availability · brand)은 Google 판매자 센터 상품 데이터와 같은 이름을 씁니다. 올리기 전에 각 서비스의 필수 항목을 한 번 확인하세요.

상품이 수백 개면 어떻게 하나요?

무료 도구는 한 번에 20개까지라 여러 번 나눠 만들 수 있습니다. 쇼핑몰 세팅은 상품 500개까지 피드와 구조화 데이터를 한 번에 넣고, 성장 관리를 켜면 상품이 바뀔 때 피드를 자동으로 갱신합니다.

상품 정보가 서버에 남나요?

공개된 상품 쪽을 읽을 때만 쓰고, 결과는 같은 주소를 다시 물을 때를 위해 6시간만 서버 캐시에 둡니다. 쪽 내용을 따로 보관하지 않습니다.

AI로 만든 상품 이미지는 꼭 표시해야 하나요?

플랫폼 · 업종마다 기준이 다릅니다. 네이버 쇼핑 광고는 AI로 만들거나 바꾼 콘텐츠에 AI 활용 표시를 요구한다고 보도되었고, Google 판매자 센터는 AI로 만든 이미지에 그 사실을 알리는 메타데이터를 넣고 지우지 말라고 안내합니다. 자동 마킹은 화면 표시 · 파일 속 정보 · 대체 텍스트를 한 번에 넣습니다. 법률 자문이 아니므로 업종별 적용은 전문가와 확인하세요.
