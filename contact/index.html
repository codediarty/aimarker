상담 전에 자주 묻는 것

콘텐츠 100건 리포트는 어떻게 받나요?

상담에서 정한 콘텐츠 100건(이미지 · 영상 · 글)으로 AI 사용 근거를 확인해, 판정 · 근거 등급 · 바로 표시할 수 있는 비율 · 제작자 확인이 필요한 목록을 리포트로 드립니다. 파일은 판독할 때만 쓰고 원본을 AIMarker 서버에 보관하지 않습니다. 비용은 받지 않고, 계약 의무도 없습니다.

바로 계약해서 쓸 수 있나요?

네. 1회 세팅(기본 49만 원 · 쇼핑몰 149만 원 · 브랜드 390만 원부터, 부가세 별도)은 상담에서 범위와 일정을 정한 뒤 견적서 · 계약서로 바로 진행합니다. 월 관리(월 9.9만 원부터)는 세팅을 마친 뒤 필요할 때 켜고 언제든 해지할 수 있습니다. 상담 전에도 GEO 진단 · 자동 마킹 · 마크 확인 · 무료 API 키(하루 300회)는 바로 쓰실 수 있습니다.

AI 사용 여부를 정확히 가려 주나요?

파일에 근거가 있을 때만 판정합니다. 서명된 출처 기록(C2PA)이나 생성 도구 기록이 있으면 그에 맞는 표시만 발급하고, 기록이 없으면 추측하지 않고 '발급자 신고'로 표시합니다. 근거와 맞지 않는 표시는 발급되지 않습니다. 마크는 법적 인증이 아니라 표시와 근거의 기록입니다.

보안 심사 · 사내 시스템 연동도 상담하나요?

네. 데이터 흐름(원본은 고객 쪽에서 판독, 특징값 · 해시만 전송) · 보관 위치 · 연동 구조(API · MCP · 대량 처리)를 함께 확인하고, 보안 요구가 높은 곳은 전용 처리와 판정 엔진 라이선스를 안내합니다.
