무엇에 AI를 사용했는지 하나하나 고르지 않아도 됩니다. 확실한 것은 바로 붙이고, 애매할 때만 묻습니다.

1

자동 진단

사이트 주소나 파일을 넣으면 출처 정보(C2PA · IPTC), 생성 도구 기록, 상담 챗봇을 먼저 찾아봅니다.

2

문구 자동 완성

찾은 내용과 업종에 맞춰 무엇에 AI를 사용했는지, 사람이 무엇을 확인하는지까지 미리 채웁니다.

3

한 번 확인

확실하면 바로 붙이고, 애매할 때만 한 번 묻습니다. 표시 책임은 운영자에게 있어 마지막 확인은 사람이 합니다.

궁금한 점을 먼저 정리했습니다

정말 무료인가요?

네. 사이트 표시, 이미지 표시(한 번에 3장), AI 활용 증빙서는 회원가입 없이 무료입니다. 이미지를 많이 처리하거나 표시 이력 · 월간 기록이 필요할 때만 유료 요금제를 고르시면 됩니다.

표시만 하면 법적 의무를 다한 건가요?

아닙니다. AIMarker는 고객에게 AI 활용을 먼저 알리는 출발점이며, 적용 대상과 방식은 사업 내용에 따라 다릅니다. 이 서비스는 법률 자문을 대신하지 않으니 중요한 판단은 전문가와 확인해 주세요.

방문자 정보를 모으나요?

모으지 않습니다. 사이트에 붙는 표시는 방문자 정보 · 쿠키를 쓰지 않고, 이미지 표시는 파일을 서버로 보내지 않고 이 브라우저 안에서만 처리합니다.

어떤 사이트에 달 수 있나요?

코드 한 줄을 넣을 수 있는 곳이면 어디든 됩니다. 아임웹 · 카페24 · 워드프레스 · 고도몰 · 쇼피파이 · 윅스 등 설치 방법을 사이트 표시 화면에서 안내합니다. 코드를 넣을 수 없는 스마트스토어 · 블로그는 이미지 표시와 글머리 문구를 쓰세요.

AI로 만든 이미지인지 어떻게 알아내나요?

파일 속 출처 정보(C2PA), IPTC 메타데이터의 'AI 생성' 기록, 생성 도구가 남긴 흔적을 읽습니다. 흔적이 지워진 파일은 알 수 없어서 그때만 한 번 묻습니다. 판별은 100%가 아니므로 마지막 확인은 운영자가 합니다.

한국AI윤리위원회와는 어떤 관계인가요?

표시 문구는 한국AI윤리위원회 기준으로 다듬었습니다. 위원회와 AIMarker는 개별 사이트나 콘텐츠를 심사 · 보증하지 않으며, 표시는 운영자가 스스로 밝히는 안내입니다.
