운영 현황

Overview

처리량 · 자동 통과 · 승인 대기 · 위험 분포를 한 화면에서 봅니다. 담당자는 오늘 판단할 것만 봅니다.

  • 검수함 현황판(상태별 개수 · 위험 점수 · 검색)운영 중
  • 조직 · 브랜드 · 캠페인별 현황개발 중

콘텐츠 출처

Content Intelligence · Origin · Fingerprint

파일 속 출처 기록과 생성 도구 흔적을 읽습니다. 기록이 지워진 파일은 '없음'이 아니라 '확인 불가'로 따로 셉니다.

  • C2PA · IPTC · XMP · 생성 설정값 판독(파일은 브라우저 안에서)운영 중
  • 사이트 진단(첫 화면 · 이미지 12장)운영 중
  • 원본 · 변형 관계, 등록 콘텐츠 재식별계획
  • 생성 도구 워터마크 검증 · 생성 도구 API 연동계획

위험 검수

Risk Review · Policy Engine

업종별 광고 규칙과 협찬 · 가상인물 · AI 표시 기준으로 위험 후보를 찾고, 근거 법령과 바꿀 말을 함께 보여 줍니다.

  • KR-AdLaw 규칙 팩 66항목 · 6개 업종 · 근거와 바꿀 말운영 중
  • 한 번에 고치기 · 다시 점검 · 맞아요 · 틀려요 의견운영 중
  • 일괄 검수(API 한 번에 20건)운영 중
  • 대량 업로드 · 검수 대기열 · 담당자 배정개발 중
  • 이미지 · 영상 속 글자 · 인물 검수계획

지금 지키는 것

  • 검수 문구는 저장하지 않음검수할 때만 서버로 보내고 남기지 않습니다. 승인 링크를 만들 때만 그 소재의 문구 · 요약을 90일 보관합니다.
  • 이미지는 브라우저 안에서출처 판독과 표시 넣기는 파일을 서버로 보내지 않습니다.
  • 원장에는 해시만내용 대신 SHA-256 해시와 서버 시각만 남깁니다.
  • API 키는 해시로 보관키는 발급할 때 한 번만 보여 드리고, 서버에는 해시만 남습니다.

  • 조직별 데이터 분리한 고객의 정책 · 가이드 · 이력은 다른 고객의 판정에 쓰지 않습니다. 개발 중
  • 보관 기간 · 내보내기 · 삭제보관 기간을 정하고, 해지하면 내보내 드린 뒤 지웁니다. 개발 중
  • SSO · 감사 로그회사 계정으로 로그인하고 모든 작업을 기록합니다. 계획
  • 전용 인프라 · 국내 보관보안 요구가 높은 기업을 위한 Private 구축입니다. 계획
