AIMarker 는 네 개의 엔진으로 움직입니다. 콘텐츠 분석 엔진이 AI 사용 여부와 범위를 확인하고, 마킹 발급 엔진이 근거와 맞는 마크를 서명해 발급하고, 이력 관리 시스템이 모든 변화를 원장에 남기고, 기업용 API가 이 흐름을 여러분의 서비스에 그대로 연결합니다.

기능마다 상태를 그대로 적었습니다. 운영 중은 지금 aimarker.kr 에서 쓰는 기능, 개발 중은 2026년 12월 기업 파일럿에서 여는 기능, 계획은 그 뒤에 만들 기능입니다.

콘텐츠 분석 엔진

AMP · AI 사용 여부와 범위 판정

파일 속 출처 기록을 기기에서 읽고, 서버가 C2PA 서명을 다시 검증한 뒤, AI 도구 지문과 판정 규칙으로 AI 생성 · 편집 · 보정 · 촬영 원본을 나눕니다. 근거의 세기도 함께 정합니다.

  • C2PA 서명 · 인증서 사슬 · 파일 결합 재검증(7가지 서명 방식)운영 중
  • IPTC · XMP · EXIF · PNG 생성 기록 판독(15가지 넘는 형식)운영 중
  • AI 도구 지문 DB · 서명자 분류(카메라 · 생성 도구 · 편집기)운영 중
  • C2PA 신뢰 목록 자동 갱신(7일마다)운영 중
  • 보이지 않는 워터마크 판독계획

마킹 발급 엔진

근거 맞춤 발급 · 전자서명

판정과 맞는 표시만 마크로 발급합니다. AI 기록이 있는 파일의 'AI 미사용', 촬영 원본 서명이 있는 파일의 AI 표시는 발급하지 않습니다. 모든 마크에 AIMarker 전자서명이 들어갑니다.

  • 근거 맞춤 발급 · 충돌 막기 · 글 확인 묻기운영 중
  • 전자서명 마크(JWS · Ed25519) · 공개키 공개운영 중
  • 보이는 배지 · 파일 속 기록(XMP) · QR · 삽입 코드운영 중
  • 대량 발급(API 한 번에 20건, 근거가 있으면 표시 자동)운영 중
  • AIMarker 서명 C2PA 출처 기록 발급계획

사용 이력 관리 시스템

마크 확인 · 이력 · 원장

누구나 마크 번호 · QR · 파일로 마크를 확인합니다. 표시 변경 · 철회 · 표시본 등록은 관리 키로만 하고, 모든 변화가 원장에 남아 매일 공개 타임스탬프에 고정됩니다.

  • 마크 확인 쪽 · 전자서명 확인 · 변경 이력운영 중
  • 표시 변경 · 철회 · 표시본 등록(관리 키)운영 중
  • 원장 · 하루치 원장 공개 타임스탬프(OpenTimestamps)운영 중
  • 지문(SHA-256 · 지각 해시)으로 다시 찾기운영 중
  • 기업 관리 화면(마크 목록 · 팀 · 권한)개발 중

기업용 API · MCP

올리는 순간 자동 확인 · 마킹

콘텐츠를 올리는 시스템에서 바로 확인하고 마크를 발급합니다. AI 에이전트는 MCP로 같은 기능을 씁니다. 원본 파일은 보내지 않고 특징값과 해시만 보냅니다.

  • API(am.analyze · am.analyzebatch · am.mark · am.markbatch · am.markinfo · am.lookup)운영 중
  • 일괄 확인 리포트(화면 · SDK · MCP, 근거 등급 · 확인할 점 · CSV)운영 중
  • MCP 서버 2.2(파일 판독 · 폴더 리포트 내장) · 함수 호출 도구 정의운영 중
  • SDK 1.1(JavaScript · Python, 일괄 확인 · 서명 확인 포함)운영 중
  • 쇼핑몰 연동(상품 등록 때 자동 마킹)계획
  • 웹훅 · 정기 리포트 자동 발송계획

  6. 6 확인누구나 마크 확인 쪽에서 표시 · 근거 · 서명 · 이력

원본 파일 · 글을 보내지 않음

판독은 사용자 기기에서 합니다. 서버에는 특징값 · 해시 · 서명 검증에 필요한 출처 기록 조각만 갑니다. 썸네일 · 위치 정보 · 프롬프트는 보내지 않습니다.

서명 키는 서버 안에서만

마크 서명 키는 서버가 스스로 만들어 서버 밖으로 내보내지 않습니다. 공개키만 공개합니다.

판정 규칙은 서버에만

판정 규칙 · AI 도구 지문 DB · 광고 규칙 팩은 공개 저장소에 두지 않고 서버에서만 씁니다.

원장에는 해시만

원장에는 내용이 아니라 해시와 서버 시각만 남고, 하루치 원장이 공개 타임스탬프에 고정됩니다.
