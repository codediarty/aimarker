엔드포인트

요청 하나, 동작은 action 으로

모든 요청은 같은 주소로 보내고, 본문의 action 으로 동작을 고릅니다. 본문은 JSON(Content-Type: text/plain), 응답도 JSON입니다.

am.verify원장 확인h 또는 idfound, kind, at, n

인증 · 한도

본문에 "key": "amk_…" 를 넣습니다. 무료 키는 하루 300회(일괄 점검은 문구 수만큼). 한도를 늘리려면 문의해 주세요.

판정 값

decision: fix(수정 후 출고) · expert(전문가 검토 권장) · review(확인 후 출고) · clear(큰 위험 후보 없음). lv: 3 높음 · 2 주의 · 1 참고.

오류

ok:false 와 code(KEY · QUOTA · TEXT · BUSY · HASH · NOT_FOUND)를 돌려줍니다. 위치 s · e 는 보낸 문구 기준(필수 표시는 -1)입니다.

바로 붙여 쓰는 예시

쓰는 도구에 맞춰 골라 보세요

시트의 확장 프로그램 → Apps Script 에 붙여 넣고 저장하면, 셀에서 =AIMARKER(A2) 처럼 씁니다. 카피 수백 줄을 한 번에 점검하는 가장 쉬운 방법입니다.

Code.gs
const AIMARKER_KEY = 'amk_여기에_발급받은_키';
const AIMARKER_URL = 'https://script.google.com/macros/s/AKfycbw3ZPLXHv92tfNVs7caH-Bf1OvMesqh0RfR8y4LCsT5DaE3otEbGWhyFLIY6FqoBEY/exec';

/**
 * 광고 문구 위험 점검. 예: =AIMARKER(A2) · =AIMARKER(A2, "cos")
 * 업종: gen 일반 · food 식품 · hfood 건강기능식품 · cos 화장품 · med 의료 · fin 금융
 * @customfunction
 */
function AIMARKER(text, ind) {
  if (!text) return '';
  const res = UrlFetchApp.fetch(AIMARKER_URL, {
    method: 'post', contentType: 'text/plain', muteHttpExceptions: true,
    payload: JSON.stringify({ action: 'am.check', key: AIMARKER_KEY, text: String(text), ind: ind || '' })
  });
  const r = JSON.parse(res.getContentText());
  if (!r.ok) return '오류: ' + r.message;
  const dec = { fix: '수정 후 출고', expert: '전문가 검토', review: '확인 후 출고', clear: '큰 위험 없음' }[r.decision];
  const top = r.findings.filter(f => f.lv >= 2).slice(0, 3).map(f => f.t || '필수 표시').join(', ');
  return r.score + '점 · ' + dec + (top ? ' · ' + top : '');
}

check.mjs
const URL = 'https://script.google.com/macros/s/AKfycbw3ZPLXHv92tfNVs7caH-Bf1OvMesqh0RfR8y4LCsT5DaE3otEbGWhyFLIY6FqoBEY/exec';

export async function aimarkerBatch(items) {
  const r = await fetch(URL, {
    method: 'POST', headers: { 'Content-Type': 'text/plain' }, redirect: 'follow',
    body: JSON.stringify({ action: 'am.batch', key: process.env.AIMARKER_KEY, items })
  }).then(x => x.json());
  if (!r.ok) throw new Error(r.code + ' ' + r.message);
  return r.results;   // [{ id, score, decision, findings, labels }]
}

// 게시 전 관문: 높음 후보가 있으면 사람 승인으로 넘김
const [res] = await aimarkerBatch([{ id: 'post-1024', text: '의사가 추천하는 다이어트 젤리' }]);
if (res.decision === 'fix' || res.decision === 'expert') console.log('사람 검토 필요', res.findings);
check.py
import json, os, requests

URL = "https://script.google.com/macros/s/AKfycbw3ZPLXHv92tfNVs7caH-Bf1OvMesqh0RfR8y4LCsT5DaE3otEbGWhyFLIY6FqoBEY/exec"

def aimarker_check(text, ind="", **flags):
    body = {"action": "am.check", "key": os.environ["AIMARKER_KEY"], "text": text, "ind": ind, "flags": flags}
    r = requests.post(URL, data=json.dumps(body).encode("utf-8"), headers={"Content-Type": "text/plain"}, timeout=30).json()
    if not r["ok"]:
        raise RuntimeError(r["code"] + " " + r["message"])
    return r

r = aimarker_check("원금 보장 확정 수익! 누구나 대출 가능", ind="fin")
print(r["score"], r["decision"], [f["t"] for f in r["findings"]])
  1. HTTP Request 노드(Make 는 HTTP 모듈)를 추가하고 Method POST, URL 에 위 주소를 넣습니다.
  2. Body 는 Raw · text/plain, 내용은 {"action":"am.check","key":"amk_…","text":"{{ $json.caption }}"}
  3. Follow Redirects(리다이렉트 따라가기)를 켭니다.
  4. 다음 노드에서 decision 이 fix · expert 면 슬랙 · 메일로 담당자에게, clear 면 바로 게시하도록 나눕니다.
  5. 승인이 필요하면 am.share 로 링크를 만들어 보내고, 일정 간격으로 am.status 를 불러 승인되면 게시합니다.
