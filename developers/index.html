도구 정의 JSON을 그대로 넣으세요. 도구 인자는 API 본문과 같아서, 실행 코드는 action 과 key 만 더해 보내면 됩니다(content 는 해시로 바꿔 h 로 보냄).

aimarker-tools.mjs
import { createHash } from 'node:crypto';
const URL = 'https://script.google.com/macros/s/AKfycbw3ZPLXHv92tfNVs7caH-Bf1OvMesqh0RfR8y4LCsT5DaE3otEbGWhyFLIY6FqoBEY/exec';
const ACTIONS = { aimarker_check: 'am.check', aimarker_check_batch: 'am.batch', aimarker_label: 'am.label', aimarker_scan_site: 'am.scan',
  aimarker_approval_status: 'am.status', aimarker_stamp: 'am.stamp', aimarker_verify: 'am.verify' };   // tools/actions.json 과 같음
const ind = (v) => (v === 'auto' ? '' : v || '');

export async function runAimarkerTool(name, args) {
  const body = { ...args, action: ACTIONS[name], key: process.env.AIMARKER_KEY };
  if ('ind' in body) body.ind = ind(body.ind);
  if (Array.isArray(body.items)) body.items = body.items.map((it) => ({ ...it, ind: ind(it.ind) }));
  if (body.content !== undefined) { body.h = createHash('sha256').update(body.content).digest('hex'); delete body.content; }
  const r = await fetch(URL, { method: 'POST', headers: { 'Content-Type': 'text/plain' }, body: JSON.stringify(body), redirect: 'follow' });
  return r.json();   // 그대로 LLM에 돌려주세요
}

에이전트 지침

AI에게 이렇게 일러 두세요

맞춤 GPT · Claude 프로젝트 · 사내 에이전트의 지침(system prompt)에 붙여 넣으면 됩니다.

지침
광고 · 상세페이지 · SNS · 보도자료 문구를 쓰거나 고치면, 사용자에게 보여 주기 전에 반드시 aimarker_check 로 검수한다.
- 대가를 받은 콘텐츠면 flags.sponsored, AI로 만든 인물 · 목소리가 나오면 flags.aiPerson, AI로 만든 이미지 · 영상이면 flags.aiMedia 를 true 로 보낸다. 모르면 사용자에게 묻는다.
- decision 이 fix 또는 expert 면 바꿀 말(reps · suggestions)과 방법(tip)을 반영해 고친 뒤 다시 검수한다. 세 번까지만 고친다.
- '(삭제)'는 그 표현을 빼라는 뜻이다. 바꿀 말이 없는 표현은 사실 정보로 다시 쓴다.
- 빠진 표시([광고] · [가상인물] · AI 생성)는 labels 의 위치대로 넣는다.
- 결과를 말할 때 위반이라고 단정하지 않고 "위험 후보"와 근거 법령으로 설명하며, 법률 자문이 아님을 알린다.
- 최종 문구와 함께 결정(decision)과 남은 후보를 짧게 보여 준다.

결정 값

decision: fix(수정 후 출고) · expert(전문가 검토 권장) · review(확인 후 출고) · clear(큰 위험 후보 없음). lv: 3 높음 · 2 주의 · 1 참고. reps 의 '(삭제)'는 빼기.

인증 · 한도

본문에 "key": "amk_…". 무료 키는 하루 300회(일괄 검수는 문구 수만큼). 한도 상향과 플랫폼 계약은 도입 상담.

오류

ok:false 와 code(KEY · QUOTA · TEXT · BUSY · HASH · NOT_FOUND …). 위치 s · e 는 보낸 문구 기준이고, 빠진 표시는 -1 입니다.

const AIMARKER_KEY = 'amk_여기에_발급받은_키';
const AIMARKER_URL = 'https://script.google.com/macros/s/AKfycbw3ZPLXHv92tfNVs7caH-Bf1OvMesqh0RfR8y4LCsT5DaE3otEbGWhyFLIY6FqoBEY/exec';

/**
 * 광고 문구 위험 검수. 예: =AIMARKER(A2) · =AIMARKER(A2, "cos")
 * 업종: gen 일반 · food 식품 · hfood 건강기능식품 · cos 화장품 · med 의료 · fin 금융
 * @customfunction
 */
function AIMARKER(text, ind) {
  if (!text) return '';
  const res = UrlFetchApp.fetch(AIMARKER_URL, {
    method: 'post', contentType: 'text/plain', muteHttpExceptions: true,
    payload: JSON.stringify({ action: 'am.check', key: AIMARKER_KEY, text: String(text), ind: ind || '' })
  });
  const r = JSON.parse(res.getContentText());
  if (!r.ok) return '오류: ' + r.message;
  const dec = { fix: '수정 후 출고', expert: '전문가 검토', review: '확인 후 출고', clear: '큰 위험 없음' }[r.decision];
  const top = r.findings.filter(f => f.lv >= 2).slice(0, 3).map(f => f.t || '필수 표시').join(', ');
  return r.score + '점 · ' + dec + (top ? ' · ' + top : '');
}

  2. Body: Raw · text/plain, 내용 {"action":"am.check","key":"amk_…","text":"{{ $json.caption }}"}
  3. Follow Redirects 켜기
  4. 다음 노드에서 decision 이 fix · expert 면 슬랙 · 메일로 담당자에게, clear 면 바로 게시
