2026년 12월에 자동 탐지 베타를 엽니다. 신청한 사이트부터 차례로 연결을 도와드리고, 베타 기간 첫 3개월은 무료입니다.

베타에서 쓰게 될 기능

  • 새 콘텐츠 자동 탐지 · 파일 속 출처 정보(C2PA · IPTC)와 생성 도구 연동 기록, 사이트 맥락(AI 상담 창)부터 찾습니다
  • 확정 신호 자동 표시 · 근거가 분명한 콘텐츠에 'AI 생성 · AI 도움' 표시를 바로 붙입니다
  • 1클릭 확인 · 애매한 것만 모아 버튼 한 번으로 정합니다
  • 이행 원장 · 월간 리포트 · 무엇을 언제 어떻게 표시했는지 고칠 수 없는 기록으로 남기고 PDF로 받습니다
  • AI 상담 창 사전 고지 · 상담 창을 찾으면 대화 전 안내를 자동으로 붙입니다

워터마크 판독 · 지문 등록부(표시 되찾기) · 자체 판별 모델은 베타 중에 차례로 더합니다.

진행 순서

  1. 신청사이트 주소와 연락처만 남기면 됩니다
  2. 연결 안내베타가 열리면 순서대로 메일로 안내합니다
  3. 1분 연결아임웹 앱 또는 코드 한 줄을 붙입니다
  4. 자동 처리 시작그다음부터는 켜 두기만 하면 됩니다

신청 전에 알아 두세요

베타 기간에도 비용이 드나요?

베타 기간 첫 3개월은 무료입니다. 그 뒤에도 자동으로 결제되지 않으며, 계속 쓰실 때만 요금제를 고르시면 됩니다.

언제 연결할 수 있나요?

2026년 12월부터 신청한 순서대로 연결 안내 메일을 보냅니다. 안내를 받으면 아임웹 앱이나 코드 한 줄로 1분 안에 연결합니다.

베타 중에 탐지가 틀리면요?

베타에서는 근거가 분명한 '확정'만 자동으로 붙이고, 나머지는 운영자에게 먼저 묻습니다. 잘못 붙은 표시는 바로 고칠 수 있고 고친 내역도 기록에 남습니다.

지금 당장 표시가 필요하면요?

베타를 기다리지 않아도 사이트 표시 만들기로 오늘 바로 사이트 전체 'AI 활용 안내'를 붙일 수 있습니다. 베타가 열리면 같은 코드에 자동 탐지를 더할 수 있습니다.
