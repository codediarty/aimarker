붙일 코드 한 줄

모든 페이지 공통, HTML

직접 붙이기 어렵다면 담당자에게 메일로 보내기, 설치 대행 문의

  1. 관리자 화면에서 환경 설정 → 코드 삽입(공통)으로 이동합니다.
  2. 바디(Body) 또는 푸터 코드 칸 맨 아래에 위 한 줄을 붙여 넣고 저장합니다.
  3. 아임웹 앱스토어에 'AI 활용 표시' 앱이 올라오면 버튼 하나로 설치할 수 있습니다(심사 중).
  1. 쇼핑몰 관리자 디자인 → 디자인 편집에서 공통 레이아웃(layout.html)을 엽니다.
  2. </body> 바로 위에 붙여 넣고 저장합니다. 모바일 디자인에도 한 번 더 넣습니다.
  1. 코드 삽입 플러그인(예: WPCode)의 Footer 칸에 붙여 넣는 방법이 가장 안전합니다.
  2. 테마를 직접 고친다면 footer.php의 </body> 바로 위에 넣습니다.
  1. 디자인 → 디자인 편집에서 하단 공통 영역(footer)을 엽니다.
  2. 맨 아래에 붙여 넣고 저장합니다. 모바일 스킨에도 한 번 더 넣습니다.
  1. 온라인 스토어 → 테마 → 코드 편집에서 theme.liquid를 엽니다.
  2. </body> 바로 위에 붙여 넣고 저장합니다.
  1. 설정 → 사용자 지정 코드 → 코드 추가를 누릅니다.
  2. 적용 범위는 모든 페이지, 위치는 Body 끝(end)으로 정하고 붙여 넣습니다.
  1. 모든 페이지에 공통으로 들어가는 HTML의 </body> 바로 위에 붙여 넣으세요.
  2. 몇 분 안에 화면 아래쪽에 'AI 활용 안내' 배지가 보이면 설치가 끝난 것입니다.
