JavaScript SDK 1.1
import { AIMarker, report } from 'https://aimarker.kr/sdk/aimarker.mjs'
const am = new AIMarker({ key: process.env.AIMARKER_KEY })
// 파일 경로 · 바이트 목록 → 20건씩 나눠 확인(원본은 보내지 않음)
const entries = await am.analyzeFiles(['./upload/a.jpg', './upload/b.png'])
const R = report.build(entries, { org: '우리 회사' })
console.log(report.summaryText(R))   // 바로 표시 가능 비율 · 확인할 점

자주 묻는 질문

몇 개까지, 얼마나 걸리나요?

한 번에 200개, 파일 하나당 300MB까지 넣을 수 있습니다. 서버는 20건씩 묶어 확인하고, 보통 100건에 1~2분 걸립니다. 출처 기록(C2PA)이 많은 파일은 서명을 다시 계산하느라 조금 더 걸립니다. 더 많은 콘텐츠는 API에 토큰 코드를 함께 보내 쓴 만큼 확인하고, 수만 건을 한 번에 처리하는 대량 처리는 문의해 주세요.

파일이 서버로 올라가나요?

아닙니다. 파일은 이 브라우저에서 읽고, 서버에는 특징값, 해시, 서명 검증에 필요한 출처 기록 조각만 보냅니다. 썸네일, 위치 정보, 작성자 정보는 빼고 보내며, 리포트도 이 기기에서 만들어집니다.

'근거 없음'은 AI를 사용하지 않았다는 뜻인가요?

아닙니다. 파일에 판단할 기록이 없다는 뜻입니다. 캡처, 다시 저장 과정에서 기록이 지워졌을 수 있어, AIMarker는 추측하지 않고 제작자, 판매자에게 확인하도록 안내합니다. 확인한 내용은 '발급자 신고' 마크로 표시할 수 있습니다.

무료인가요?

지금은 무료로 이용할 수 있습니다(브라우저 하나에서 1시간에 300건까지). 매일 수천 건을 확인하거나 정기 리포트, 쇼핑몰 연동이 필요하면 1회 세팅과 월 관리를 토큰이나 카드로 바로 주문하고, 대량 처리는 문의해 주세요(토큰 가격표).

이 리포트를 법적 증빙으로 사용해도 되나요?

리포트는 출처 기록과 서명으로 판정한 결과를 정리한 것으로, 법률 자문이나 적법성 보증이 아닙니다. 표시를 붙인 기록이 필요하면 근거 맞춤 마크를 발급하세요. 마크마다 전자서명과 원장 기록이 남습니다.

리포트를 보고, 우리 업무에 붙여 보세요

기업 파일럿을 신청하면 콘텐츠 100건 리포트를 함께 읽고, 콘텐츠를 올리는 순간 자동으로 확인, 마킹하는 방식을 4주 동안 실제 업무에 적용해 봅니다.
